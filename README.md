# Komentář k zákonu č. 266/1994 Sb., o dráhách

Odborný komentář k **zákonu č. 266/1994 Sb., o dráhách** — kodexu železničního práva: kategorie drah, oddělení provozování dráhy a drážní dopravy, přidělování kapacity, licence dopravců a osvědčení strojvedoucích, interoperabilita, práva cestujících, Drážní úřad a Drážní inspekce.

Konsolidované znění: dokument e-Sbírky `SB-1994-00266_2025-09-10`.
